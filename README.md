# 🌈 Color Switch — Unity

**Unity ve C#** kullanılarak geliştirilmiş 2D arcade oyun projesi.

## 🎮 Oyun Hakkında

Color Switch, oyuncunun kendi rengiyle eşleşen bölümlerden geçerek engelleri aşmaya ve mümkün olduğunca yüksek skor elde etmeye çalıştığı hızlı tempolu bir 2D arcade oyunudur.

Bu proje; **oyuncu kontrolü, renk değiştirme sistemi, rastgeleleştirme, çarpışma kontrolü, kamera takibi ve skor sistemleri** üzerinde çalışmak amacıyla geliştirilmiştir.

## ✨ Özellikler

- 🎮 Oyuncu hareket ve kontrol sistemi
- 🌈 Dört farklı renk sistemi
- 🔄 Renk değiştirme mekaniği
- 🎲 Rastgele renk ve engel sistemi
- 💥 Çarpışma kontrolü
- 🏆 Skor sistemi
- 🪙 Coin toplama sistemi
- 📷 Kamera takip sistemi
- ☠️ Oyun sonu sistemi
- 🔄 Yeniden başlatma sistemi
